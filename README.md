# Kevin & Treesa — Wedding Website

A single-page wedding website for the Holy Matrimony of Kevin Jose & Dr. Treesa Syril,
16 January 2027 — styled as an aged, old-world broadsheet.

- `index.html` — the entire site (HTML, CSS, JS inline)
- `assets/` — web-optimized photographs
- `photos/` — original full-resolution photographs

No build step; open `index.html` or serve the folder statically.
